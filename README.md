# Клуб Самокатов — landing page

Адаптивный одностраничный лендинг. Вёрстка по макету из Figma, который дали в тестовом задании Яндекса (Яндекс Go / «Клуб Самокатов»).

> **Тестовое задание** при отклике на вакансию frontend/вёрстки (Яндекс Go / «Клуб Самокатов»). В брифе дали макет в Figma: лендинг абонемента в клуб самокатов с брендингом Яндекс Go. Этот репозиторий и демо — **моя вёрстка для портфолио**, не официальный сайт Яндекса и не аффилированы с компанией.
>
> Чтобы не использовать чужие товарные знаки в демо, бренд в интерфейсе заменён: логотип «Яндекс Go» → **Scooter Club**, обновлены favicon и тексты/подписи с упоминанием Яндекса. Композиция и сценарии секций по-прежнему опираются на исходный учебный макет. Код позже дорабатывался.

## Demo

После первого деплоя ссылка будет вида:

`https://<username>.github.io/<repo>/`

## Стек

HTML · SCSS (BEM) · JavaScript · Gulp · Webpack · Swiper

## Реализовано

- Адаптивная вёрстка (desktop → tablet → mobile)
- Оптимизация изображений: WebP, lazy loading, SVG-спрайт
- Анимации появления блоков при скролле
- Swiper-слайдер на мобильных устройствах
- Sticky-кнопка CTA на мобилке
- Поддержка `prefers-reduced-motion`

## Запуск локально

```bash
npm install
npm run dev    # разработка с BrowserSync
npm run build  # production-сборка в папку app/
```

## Проверки

```bash
npm run lint          # Stylelint
npm run stylelint:fix
```

## Структура проекта

```
src/
├── partials/     # HTML-компоненты (gulp-file-include)
├── scss/         # Стили (BEM)
├── js/           # Скрипты
├── img/          # Изображения и SVG-иконки
└── resources/    # Шрифты, favicon
app/              # Сборка (не в git, появляется после build)
```

## Деплой

После `git push` в `main` проект собирается и публикуется на GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`).

После деплоя в `src/partials/head.html` укажите абсолютные URL для `og:url` и `og:image`.
